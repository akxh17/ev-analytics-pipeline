# EV Analytics Pipeline

An end-to-end data analytics pipeline for electric vehicle (EV) data.
The project covers data ingestion, cleaning, analysis, and visualization.

## Tech Stack
- Python
- Pandas, NumPy
- SQL / SQLite (later)
- Visualization (Matplotlib / Power BI / Streamlit)

## Setup
1. Create a virtual environment
2. Install dependencies
3. Run the pipeline
